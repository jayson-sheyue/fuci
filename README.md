# 浮词

常驻在 macOS 屏幕上的悬浮词典。输入英语或日语单词，会展开一张白板，上面有中文译文、音标或读音、词性、英英 / 日日释义和例句。输入句子时，只把整句译成中文。输入中文时方向反过来，并按「中文译成」译成英语或日语。简体字和两边相同的汉字（如中国人）按中文查；日文常用、简体中文不用的字形（如時、東、語、強）按日语查。带假名的仍按日语查。搜索框里的「自动」可以改成指定中文、日语或英语，点一下切换，当前查询会按指定语言重查。单词卡片会列出形态变化；句子除整句译文外，还有逐词释义。出现的英文单词和句子都标国际音标，日文单词和句子都标假名；中译英、中译日的译文也一样。英语和日语的单词、例句和整句旁边有小喇叭，点一下会用 Cloud Text-to-Speech 的 Gemini 3.1 Flash TTS（Kore）朗读；如果这个预览模型不可用，会改用 Gemini 2.5 Pro TTS。

## 启动

双击桌面上的「浮词.app」。它和项目里的 `dist/浮词.app` 是同一份应用。

从源码重新打包：

```bash
npm install
npm run pack
```

开发时也可以 `npm start`。搜索条会停在所有桌面的最上层。`⌘⇧Space` 呼出（如果被占用，则改用 `⌘⇧D`）。双击左侧放大镜收成悬浮球，双击悬浮球再展开。按住放大镜或悬浮球可以拖动。`Esc` 先收起白板，再按一次收成悬浮球。搜索框上的语言按钮默认是「自动」，点一下依次改成中文、日语、英语。

## 连接 GCP

仓库里没有项目 ID、访问令牌或 Google 账号，这些只保存在本机。设置里填写项目 ID、Location 和模型 ID。点「一键链接」后，应用执行 `gcloud auth print-access-token` 取得大约 1 小时的访问令牌。如果 gcloud 还没登录，会自动打开浏览器完成 `gcloud auth login`。右侧倒计时结束或显示已失效时，再点一次一键链接。同一页的「面板不透明度」拉杆会同时调整搜索框和结果板，默认 88%，拖动后立即生效。「外文译成」决定英语和日语译成简体还是繁体；「中文译成」决定中文单词和句子译成英语还是日语。改完这两项后，当前查询会按新方向重查。

项目需要已开通结算，并启用 Cloud Translation API 和 Vertex AI API。登录的账号需要有这两个 API 的调用权限。

单词查询会同时调用两个接口：

- **Cloud Translation API**：译文。英语和日语译成中文，中文译成设置里选择的英语或日语。句子也优先走这里
- **Vertex AI Gemini**（默认 `gemini-3.8-flash`，区域 `global`）：英语和日语词条的音标或假名，中文词条的拼音，以及词性、释义和例句

如果 Cloud Translation 还没启用，句子会先由 Gemini 翻译，白板底部会写明。启用之后自动改走翻译接口。词条由模型生成，生僻读音建议再核对。

如果 `npm start` 说 Electron 没有安装成功，通常是公司证书挡住了 Node 的下载。改用系统自带的 curl 下载 `electron-v版本号-darwin-arm64.zip`，解压到 `node_modules/electron/dist`，并让 `node_modules/electron/path.txt` 的内容为 `Electron.app/Contents/MacOS/Electron`。
